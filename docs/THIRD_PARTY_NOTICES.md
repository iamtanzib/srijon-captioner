# Third-Party Components

This project integrates with but does not bundle full distributions of:

- Adobe Premiere Pro / UXP
- WhisperX
- PyTorch / torchaudio / torchvision
- FastAPI
- Uvicorn
- Pydantic
- FFmpeg

The setup script installs dependencies through their normal package channels. Review applicable third-party licenses before redistributing the project commercially or publicly.
